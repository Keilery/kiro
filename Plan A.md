# NexusMarket — Полный план реализации (552 функции)  
  
## 📋 Общая концепция  
  
**Название проекта:** `NexusMarket` — платформа для продажи игровых предметов, услуг и автоматизации  
  
**Стек технологий:**  
- **Frontend:** Next.js 14 + TypeScript + Tailwind CSS + Framer Motion  
- **Backend:** Node.js + Express.js  
- **Database:** PostgreSQL + Redis (кэш)  
- **Auth:** JWT + OAuth2 (Google, Discord, Steam)  
- **API:** REST + GraphQL + WebSocket  
- **Storage:** AWS S3 / Cloudflare R2  
- **Deploy:** Docker + Nginx + PM2
